PHASE 6 -- FOOD PATCHES + OPERANT SCHEDULES
-------------------------------------------
[x] Single renewable food patch: logistic regrowth + depletion on contact;
    food intensity/contact scale with biomass (VI-like availability). Max
    regrowth (rK/4) < intake rate, so a camper depletes to the floor then lives
    off the steady regrowth.
[x] Concurrent VI-VI matching via DISCRIMINATIVE CUES (matching.py): two
    cue-marked patches (one cue dimension, not new food channels) on different VI
    schedules; learned cue->rate value (CueReceptorField-style) drives approach;
    travel between patches = COD. GML fit log(B_L/B_R)=a*log(R_L/R_R)+log b gives
    a=0.69 (undermatching, as in real animals), R^2=0.80. exp008_matching.
[x] Sweep COD (patch separation / travel): matching sensitivity a rises with
    COD -- 0.04 (sep2) -> 0.88 (sep14), reproducing Shull & Pliskoff. exp009.
[x] Multi-alternative matching (exp010): N=5 cue-marked patches on a circle,
    alt-vs-rest GML a=0.99, R^2=0.75 -- near-perfect matching, no new machinery.
[x] Canonical counterbalanced matching (exp012): ratios 9:1..1:9 + 1:1,
    cue<->side counterbalanced. Found a spurious SIDE bias from an even-grid
    wall asymmetry; fixed with an odd grid (MatchConfig.grid_size 10->11). Bias
    -> 0 across all matching exps; cue bias provably 0.
[x] Concatenated matching law -- AMOUNT term (exp011): identical VI, sweep amount
    ratio -> a_amt=0.97 (near-perfect), bias 0 after the geometry fix. Separable
    from rate sensitivity.
[x] Concatenated matching law -- PROBABILITY (exp013, a_p=0.78) and DELAY
    (exp014, a_d=0.61, hyperbolic/exponential selectable) terms. All four
    dimensions (rate/amount/probability/delay) reproduced with separable
    sensitivities, ~0 bias. Delay = reduced reinforcer EFFICACY (not credit-decay).
[ ] Combined-dimension test: vary 2+ concatenated-GML dimensions at once;
    confirm the law holds additively in log space (sensitivities combine).
[x] Fit the sensitivities (exp023): search organism params so the emergent
    (a_rate, a_amt) hit targets, then re-plug into the stochastic engine to confirm
    transfer. Free params temperature/approach_gain/beta; beta is the dominant,
    sign-consistent lever (lr_cue EXCLUDED -- its rate effect does not transfer).
    KEY FINDING: autodiff is NOT usable here -- reverse-mode gradients through the
    ~1000-step recurrent rollout explode (~1000x too large, sign-unstable vs a clean
    finite-difference). And a molar closed-form (where autodiff WOULD be clean) has to
    assume B_k ~ v_k^a, imposing the sensitivity instead of letting it emerge. So we
    keep the emergent dynamics and search the smooth Gumbel-softmax surrogate
    (matching_diff) derivative-free (Nelder-Mead, fit.py). On this 2-patch prep the two
    sensitivities are positively coupled (beta moves both), so the demo tunes them in
    aligned directions: stochastic a_rate 0.56 -> 0.66 (up) / 0.36 (down), a_amt 0.97
    -> 1.06 / 0.86. Strong decoupling needs the environmental COD lever (exp009), not
    organism params.
[x] Decouple a_rate from a_amt (exp024). FINDING: the COD/separation lever does NOT
    decouple -- it raises BOTH sensitivities (new result; exp009 only ever measured
    rate). All discriminability levers (beta, COD, ~temperature) scale overall
    sensitivity; they're redundant, not orthogonal. The fix is an asymmetric lever: a
    reinforcer-magnitude sensitivity exponent amount_exponent=rho (value tracks
    amount^rho, utility curvature). Since a_rate is measured at equal amounts
    (amount^rho=1), rho moves a_amt and leaves a_rate EXACTLY flat (verified in both
    engines). With beta for a_rate and rho for a_amt, crossing targets are reachable:
    exp024 fits A (rate^/amt_v -> stoch 0.59/0.61) and B (rate_v/amt^ -> 0.39/1.20),
    impossible on the old coupled manifold; decoupling transfers (a_rate A>B, a_amt A<B).
[ ] Revisit autodiff via truncated backprop (TBPTT) if a gradient method is wanted
    (the forward surrogate is fine; only the full-rollout reverse gradient explodes).
[x] a_prob / a_delay decoupling (exp025). The rho pattern GENERALIZES: each graded
    concatenated dimension has its own orthogonal curvature lever, with rate the
    frequency anchor set by the discriminability knobs (beta etc.):
      amount -> amount_exponent (rho)         value ~ amount^rho
      delay  -> delay_k                        hyperbolic discount steepness (already existed)
      prob   -> probability_exponent (sigma)   reinforcement gated on prob^sigma (NEW)
    Probe confirmed beta scales all four; rho/delay_k/sigma each move ONLY their own
    dimension (the other sweeps hold that dim neutral: amount=1, prob=1, delay=0).
    sigma is nonlinear probability weighting (prospect-theory flavor). exp025 fits
    crossing (a_prob, a_delay) targets via sigma + delay_k: A (prob^/delay_v -> stoch
    0.93/0.45) and B (prob_v/delay^ -> 0.50/0.64); decoupling transfers (a_prob A>B,
    a_delay A<B). All four GML sensitivities are now independently tunable.
[~] Behavioral momentum demonstration (exp022, chamber.run_multiple_schedule):
    multiple schedule, rich (VI 5) vs lean (VI 40) components, each with a
    Pavlovian context->reinforcer value (rate-graded "mass"). DONE under the
    SATIATION/prefeeding disruptor: rich retains 99.6% of baseline, lean 80% --
    rich more resistant (momentum), because its higher context value is a larger
    non-motivational share of the drive. NOT clean under EXTINCTION (anti-momentum):
    in this energy world extinction = starvation (raises drive, masks extinction),
    value decay is response-based (vigorous response self-extinguishes), and both
    components fall to a shared emission floor so proportion tracks baseline height.
    Future work: decouple reinforcement from survival + floor-free, time-based,
    mass-scaled decay. Unit inertia (1/mass) already tested separately.
[x] Multiple renewable food patches in the survival world (patch-leaving / MVT).
    forage.py adds a multi-patch food layer to the JAX SURVIVAL world (energy/
    death, unlike matching.py): organism approaches the most SALIENT patch
    (salience = exp(-d/range)*biomass_frac); feeding depletes the occupant while
    the alternative regrows; the consume atom holds it until the distant patch's
    salience wins, then it leaves. P=1 reproduces make_simulate to 0.0e+00
    (test_forage). exp020: give-up density FALLS (0.60->0.43) and residence RISES
    (38->62 steps) with travel distance D=3..7 -- marginal-value theorem. Clean
    only for D <= sensor_range (set to 12); beyond that the far patch isn't sensed.
    Give-up density = kappa*exp(-D/range), kappa~=0.79 (constant tenacity factor =
    consummatory perseveration; consume gain 1.0 > approach 0.5 + integrator lag).
    exp021 adds the Holling functional response (food_intake_scaling='biomass'):
    at equal rate it lifts end-of-run survival 0.00->0.50 (depleted patch -> less
    intake -> hunger re-engages) and makes give-up RATE (rate*density, 0.044->0.034
    with D) a literal Charnov marginal-value signature. MVT gradient holds in both
    regimes; only the functional response is Charnov-interpretable + viable.

    Acquisition latency 152->106; trained hw_food 1.0 extinguishes to ~0 over
    a few unreinforced lives (run_extinction_demo).
